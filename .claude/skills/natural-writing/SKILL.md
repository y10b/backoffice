# natural-writing — AI 티 안 나는 글

AI 판별기가 잡는 다섯 가지 단서(문장 균일성 · 너무 완벽한 논리 · 경험·감정 부재 · 안전한 어휘 ·
도구 점수)를 거꾸로 쓴 규칙이다. 목표는 탐지기를 속이는 게 아니라 **사람이 읽고 싶은 글**이다 —
네이버 저품질·유사문서 필터와 독자 이탈도 같은 단서에 반응한다.

## 절대 규칙 — 경험은 지어내지 않는다

단서 3(구체적 경험·감정)이 가장 강력하지만, 그래서 가장 위험하다.

- 디테일은 **근거에 있는 것만** 쓴다: 사진 분석, 인터뷰 답, 커밋 메시지, 상세페이지 캡처, 공식 출처
- 근거가 빈약하면 글을 짧게 쓴다. 겪지 않은 장면·감정을 채워 넣지 않는다
- 복합 감정("씁쓸하면서도 다행")은 사용자가 그렇게 말했을 때만 쓴다
- 제휴 링크가 붙은 글에서 지어낸 사용 경험은 표시광고법 위반이다

사람처럼 보이려고 거짓말하면 그건 사람 글이 아니라 가짜 후기다.

## 1. 문장 길이를 흔든다

- 한 문단에 짧은 문장(10자 안팎)과 긴 문장(50자 이상)이 섞이게. 20~30자 문장만 줄줄이 이어지면 고친다
- 종결 어미를 섞는다. 채널 톤 안에서:
  - 네이버(친근한 존댓말): ~어요 / ~더라구요 / ~거든요 / ~잖아요 / ~네요 / 명사로 끊기("양은 넉넉.")
  - 티스토리(정보형): ~입니다 사이에 ~예요·~죠·질문형을 끼운다. "~입니다" 3연속 금지
  - velog(개발 로그): ~했다 / ~였다 평서체 안에서 짧은 단문·체언 종결로 리듬을 준다
- **같은 어미 3연속 금지.** 10문장 단위로 어미 분포를 세 본다

## 2. 논리를 일부러 덜 매끈하게

- "첫째, 둘째, 셋째" · "결론적으로" · "요약하자면" 템플릿 금지 (정보형 목록이 꼭 필요하면 번호 목록 UI 로)
- 모든 문단이 주제문 → 설명 → 예시 순서면 몇 개는 순서를 바꾸거나 예시부터 시작
- 근거 있는 곁가지 한 줄은 남긴다 (인터뷰에서 나온 딴 얘기, 커밋에서 헤맨 흔적)
- 마무리에 교훈·총정리를 붙이지 않는다. 할 말 끝나면 끝낸다

## 3. 디테일은 숫자와 고유명사로

근거 안에서 가장 구체적인 것을 고른다: "가격이 괜찮았다" → "2인 세트 32,000원(방문 당시)",
"빨랐다" → "빌드 41초 → 12초". 일반론 문장 하나를 지울 때마다 근거의 구체적 사실 하나를 넣는다.

## 4. 안전한 어휘 걷어내기

AI 상투어 — 보이면 지우거나 바꾼다:

> ~에 대해 알아보겠습니다 · 다양한 · 효과적인 · 중요한 역할을 합니다 · ~하는 것이 좋습니다 ·
> 살펴보겠습니다 · 마무리하며 · 도움이 되셨길 바랍니다 · 결론적으로 · 뿐만 아니라 · 한편 ·
> 꿀팁 · 완벽 정리 · 총정리 · 놓치지 마세요 · 인상적이었습니다 · 만족스러웠습니다

- 같은 대상을 같은 단어로만 부르지 않는다. 대신 동의어 사전식 돌려막기도 금지
- 그 분야 사람이 쓰는 말을 자연스럽게: 맛집(웨이팅·회전율·밑반찬 리필), 세금(원천징수·귀속연도·
  경비율), 개발(롤백·핫픽스·N+1). 단, 독자가 모를 약어는 처음 한 번 풀어 쓴다

## 5. 자가 점검 (퇴고 끝에 한 번)

- [ ] 문장 길이: 가장 짧은 문장과 가장 긴 문장 차이가 3배 이상인가
- [ ] 같은 어미 3연속이 없는가
- [ ] 위 상투어 목록이 0개인가
- [ ] "첫째/둘째", 총정리 마무리가 없는가
- [ ] 모든 구체적 디테일이 근거(사진·인터뷰·커밋·출처)에서 왔는가 ← 하나라도 아니면 지운다
- [ ] 소리 내어 읽었을 때 걸리는 데가 없는가

탐지 도구 점수는 참고만 한다. 100% 맞는 도구는 없고, 점수를 낮추려고 근거를 버리면 본말전도다.
200자 미만 짧은 글은 점검하지 않는다.
