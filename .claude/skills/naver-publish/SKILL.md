# naver-publish — 네이버 블로그 종류별 하루 한 편

흐름: 휴대폰 `/visit` 에서 사진 → 30초 인터뷰 → 초안 → **자동 발행 맡기기** (사진·대가성 이미지까지
담긴 완성본이 Storage `naver-queue` 에 들어가고 상태가 `ready`) → 이 스킬이 종류마다 하루 한 편씩,
하루 최대 세 편(음식점 `restaurant` · 상품 `product` · 일상 `daily`) 올린다.

## 불변 원칙 (저품질·법 위반을 막는 선)

1. **맡겨진 글만 올린다.** 대기열이 비면 그날은 쉰다. 글을 새로 지어내거나, 안 가본 가게·안 써본
   제품 후기를 만들지 않는다 — 제휴 링크가 붙은 지어낸 후기는 표시광고법 위반이고 쿠팡·세시간전
   정산 환수 사유다.
2. **외부 이미지를 긁어 넣지 않는다.** 남의 사진은 저작권 침해이고, 네이버는 이미 웹에 있는 이미지를
   중복 이미지로 걸러 저품질 신호로 쓴다. 사진은 사용자가 찍은 것만.
   예외는 발행 스크립트가 넣는 **AI 연출 이미지** 한 장이다(상품·일상 글, `OPENAI_API_KEY` 가 있을 때).
   제품은 그리지 않고 장면만 만들며 바로 아래에 "AI로 만든 연출 이미지입니다. 실제 제품·사용 사진이
   아닙니다." 를 단다. 이 문구를 지우거나 실제 사용 사진처럼 소개하지 않는다. 빼려면 `--no-ai-image`.
3. **종류별 하루 한 편, 하루 최대 세 편.** 같은 종류 두 편은 올리지 않는다. 몰아 올리기는 어뷰징 신호다.
   루틴이 종류를 정해 부르면(예: "음식점 한 편") 그 종류만 올린다. 정하지 않으면 종류마다 한 편씩 올리되,
   비어 있는 종류는 다른 종류로 채우지 않는다.
4. **대가성 표시는 맨 위.** 제휴 링크가 있는 글에 대가성 문구 이미지(또는 첫 줄 문구)가 없으면 올리지
   않는다(공정위 2024-12 지침: 제목 또는 첫 부분). 세시간전 쿠팡 링크는 승인된 네이버 블로그에서만
   정산된다.
5. 댓글·공감·이웃 품앗이, 키워드 반복 삽입, 숨긴 텍스트는 하지 않는다.

## 준비

```bash
test -n "$SUPABASE_URL" && test -n "$SUPABASE_SERVICE_ROLE_KEY" || echo "Supabase 키 없음 — 중단"
test -n "$NID_AUT" && test -n "$NID_SES" || echo "NID 쿠키 없음 — 설정 표 naver_nid_aut/ses 를 쓰거나 중단"
npm ci --omit=dev
R="node --import ./scripts/ts-register.mjs"
```

## 1. 고르기 · 검토

```bash
$R scripts/naver-publish.mjs list
$R scripts/naver-publish.mjs show <id>
```

종류(`list` 의 세 번째 칸)마다 가장 오래 기다린 것부터. 올리지 않고 보고만 하는 경우:
- `warnings`·`needs_check` 에 폐업 의심, 가격 근거 없음이 남아 있음
- 본문이 `natural-writing` 스킬 점검에서 크게 걸림 (상투어 범벅, 같은 어미 반복) — 본문은 사진과
  묶인 완성본이라 여기서 고치지 않는다. 사용자가 `/visit` 에서 "고쳐 쓰기" 후 다시 맡기게 보고
- 제휴 링크가 있는데 대가성 표시가 첫 부분에 없음

## 2. 발행

```bash
$R scripts/naver-publish.mjs publish <id> --private   # 첫 시험·셀렉터 확인용 (상태 그대로)
$R scripts/naver-publish.mjs publish <id>             # 공개. 성공하면 posted, 대기열에서 지움
```

실패하면 `naver-fail.png` 를 본다.
- 로그인 화면 → NID 쿠키 만료. 다시 시도하지 말고 새 쿠키가 필요하다고 보고
- "사진이 에디터에 안 들어갔습니다" → 사진 없는 글을 올리지 않는다. 보고
- 셀렉터 단계 실패 → 스마트에디터가 바뀐 것. 대화형 세션에서만 스크린샷을 보고 고친다
- 스크린샷은 커밋·공유하지 않는다 (계정 화면이 찍힌다)

## 3. 보고

종류별로 올린 글 제목·주소, 건너뛴 글과 이유, 종류별 대기열에 남은 편수(0편인 종류는 "사진을 더 맡겨 주세요").
