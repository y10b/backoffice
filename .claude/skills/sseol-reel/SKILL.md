# 썰 릴스 제작 (+ 인스타 업로드)

인스타 일상 썰 채널용. 사용자는 썰만 대충 던지고, 질문 → 대본 → 영상 → 업로드는 Claude가 한다.
스타일 기준은 `references/style-guide.md`, 대본 파일 문법은 `references/spec-format.md`, 완성 예시는 `examples/toilet_boss.py`.

## 0. 준비 (세션마다 한 번)

```bash
bash .claude/skills/sseol-reel/scripts/setup.sh
```
결과물은 스크래치패드(없으면 작업 폴더 밖 임시 폴더)에 저장한다. **레포에 영상을 커밋하지 않는다.**

## 1. 썰 인터뷰

- 썰이 없으면 주제를 던진다 (민망했던 순간, 잘못 보낸 카톡, 알바 진상, 썸/연애 황당 순간...).
- 썰을 받으면 `style-guide.md`의 인터뷰 항목대로 질문한다. 한 번에 3~7개, 번호 붙여서. 보통 2~3번 주고받으면 충분하다.
- 이전 썰의 "다음 썰 예고"를 이어받는 편이면 오프닝을 "지난 썰에서 ~했잖아요?"로 시리즈처럼 연다.
- **엔딩용 다음 썰 주제**도 물어본다 (모르면 가린 카드로).

## 2. 대본 작성

`style-guide.md`대로: 결말부터 보여주는 훅 → ⏪ 10분 전 → 빌드업 → 클라이맥스 → 수습 → 반전 → 팔로우 유도 + 다음 썰 예고. 해요체 오버 더빙, 개그 장치 5~8개, 60초 안팎.

등장인물은 **그림 캐스트(`cast()`)로 연기**시키는 게 기본이다 (역할 배정: 썸녀 역 = `she` 등, 목록은 `cast/`). 장소 배경(`bg=`)과 빡침 장면 집중선도 같이 쓴다. 문법은 spec-format.md의 '장면 배경 / 캐릭터 연기'.

대본 파일을 스크래치패드에 `<이름>.py`로 쓴다 (`examples/toilet_boss.py`를 복사해서 고치는 게 제일 빠름).

## 3. 미리보기 → 확인 → 렌더

```bash
R=.claude/skills/sseol-reel/scripts/render.py
python3 $R SPEC.py --out OUTDIR --preview   # 대사별 화면을 한 장에 (TTS도 이때 생성/캐시)
python3 $R SPEC.py --out OUTDIR             # 영상 + 커버 (60초 영상 약 1분)
```

- preview PNG를 **직접 열어 보고** 자막 잘림, 겹침, 깨진 글자(□), 빈 화면을 고친다.
- 길이가 75초를 넘으면 대사를 줄이거나 합친다.
- 영상과 커버는 SendUserFile로 보낸다. 함께 전할 것:
  - 장면별 개그 요약 (짧은 표)
  - **지어낸 디테일이 있으면 명시**
  - 업로드 캡션 + 해시태그 (style-guide 형식)
  - Claude는 소리를 직접 못 들으니 톤과 발음은 들어보고 짚어달라고 한 줄
- 수정 요청은 대본 파일만 고쳐서 다시 렌더한다 (TTS 캐시 덕에 바뀐 대사만 새로 생성).

## 4. 인스타 업로드 (선택)

조건: 환경변수 `IG_USER_ID`, `IG_ACCESS_TOKEN`이 있고 네트워크가 graph.facebook.com / rupload.facebook.com을 허용해야 한다. 없으면 `references/instagram-setup.md`를 보고 설정 방법을 짧게 안내한다. **토큰을 채팅에 붙여넣으라고 하지 않는다.** 그동안 영상 파일은 직접 올리도록 넘긴다.

1. 캡션을 `CAPTION.txt`로 저장
2. 점검(dry run): `python3 .claude/skills/sseol-reel/scripts/upload_instagram.py VIDEO.mp4 --caption-file CAPTION.txt --thumb-ms <커버 시각 ms>`
3. 사용자에게 **계정명, 영상, 캡션을 보여주고 "올릴까요?"라고 명시적으로 확인**받는다. 게시는 공개되고 되돌리기 어렵다. 이전에 받은 승인은 새 영상에 적용되지 않는다.
4. 확인되면 같은 명령에 `--yes`를 붙여 실행하고, 게시 링크를 전달한다.

API 업로드는 인스타 앱 음악을 못 붙인다. 음악을 원하면 앱에서 직접 올리는 쪽을 안내한다.

## 계정 운영 원칙 (사용자 결정)

- 이 인스타 계정은 **Claude가 제작·운영하는 계정임을 공개**하고, **썰은 실제 사용자 본인의 실화**라고 밝힌다.
- 캡션 끝에 공개 문구를 넣는다: `🤖 영상 제작: Claude (AI) · 썰: 운영자 실화`
- 업로드 시 인스타의 AI 라벨(AI 정보 표시)을 켜도록 안내한다. API 업로드로 라벨이 붙지 않으면 앱에서 켜도록 알려준다.
- 실화를 각색한 부분(지어낸 카톡 문구 등)이 있으면 사용자에게 알리는 원칙은 그대로 유지한다.

## 주의

- 음성은 edge-tts(마이크로소프트 무료 음성). 수익 채널에서 쓰는 건 약관상 애매하다고 처음 한 번 알려준다. 직접 녹음이나 유료 TTS(타입캐스트, 일레븐랩스) 파일을 쓰려면 render.py에 외부 음성 입력을 추가해야 한다 (현재 미지원).
- 실존 인물을 특정할 수 있는 정보(이름, 학교, 회사, 얼굴)는 영상에 넣지 않는다.
