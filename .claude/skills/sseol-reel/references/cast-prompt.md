# 캐릭터 시트 프롬프트 (ChatGPT 이미지 생성용)

같은 대화방에서 순서대로 만들고, 2번째부터는 맨 앞에 "앞에서 만든 시트와 똑같은 그림체, 등신, 선 굵기, 크기로"를 붙인다.

```
웹툰 스타일 캐릭터 시트 1장을 그려줘.

[형식]
- 가로로 긴 이미지 (3:2 비율), 2줄 x 4칸 격자, 총 8칸
- 8칸 모두 같은 캐릭터 1명, 머리부터 발끝까지 전신, 정면을 보고 서 있는 모습
- 모든 칸의 캐릭터 크기와 발 위치를 똑같이 맞춰줘
- 캐릭터끼리 겹치지 않게 칸 사이 여백을 넉넉히
- 배경은 전체가 완전한 단색 초록(#00FF00). 그림자, 바닥, 무늬, 칸 테두리, 글자 전부 넣지 마
- 캐릭터 옷이나 소품에 초록색은 쓰지 마

[그림체]
- 한국 썰툰 느낌의 귀여운 2.5등신 SD 캐릭터
- 굵고 깔끔한 검은 외곽선, 단순한 플랫 컬러, 표정을 과장되게
- 8칸 모두 얼굴, 머리, 옷을 똑같이 유지

[캐릭터]
(캐릭터 설명)

[8칸 표정·포즈 - 윗줄 왼쪽부터, 그다음 아랫줄 왼쪽부터]
1. 기본: 편한 표정으로 차렷
2. 웃음: 눈웃음 지으며 활짝 웃음
3. 폰 보기: 한 손에 스마트폰을 들고 화면을 보며 설렘, 볼이 살짝 빨개짐
4. 놀람: 눈이 동그랗고 입을 크게 벌림, 머리 위에 느낌표
5. 빡침: 얼굴이 빨갛고 이를 악물고 두 주먹을 위로 듦, 머리에서 김이 나고 화난 표시(💢)
6. 현타: 영혼 나간 무표정, 눈이 반쯤 감김, 어깨가 축 처짐
7. 슬픔: 한 손으로 얼굴을 감싸고 눈물 한 방울
8. 뻔뻔: 어깨를 으쓱하며 "왜?" 하는 당당한 표정
```

실존 인물과 닮지 않게 일반적인 외모로 설명한다.
