# 썰 대본 스타일 가이드

사용자와 여러 번 고쳐서 정착한 스타일. 기본값으로 따르고, 사용자가 다른 걸 원하면 그쪽을 따른다.

## 인터뷰 (썰 듣기)

썰은 대충 와도 된다. 한 번에 3~7개, 번호 붙여서 묻는다. 꼭 채울 것:

1. **상황**: 언제/어디/왜 거기 있었나, 누구를 기다리거나 같이 있었나 (긴장감 재료)
2. **실수/사건의 원인**: 왜 그렇게 됐나 (착각, 급함, 취함...)
3. **클라이맥스**: 상대 반응(표정, 말, 눈빛), 내 행동, **그때 속마음**
4. **결말/후일담**: 어떻게 빠져나왔나, 들켰나, 그 뒤 관계는
5. 등장인물이 한 말 그대로 기억나는 것 (대사로 쓰기 좋음)

웃긴 디테일(예: "소변기가 없네? 그런가 보다 했지")이 나오면 바로 짚어서 칭찬하고 킬포로 쓴다고 알려준다.

## 사실 vs 연출

- 실제 사건(누가, 무엇을, 결과)은 **사용자가 말한 대로만**. 없는 사건을 만들지 않는다.
- 비유·과장·게임 프레이밍·속마음 해석(보스전, IQ -50, 연기대상)은 자유.
- 대사/카톡 내용처럼 사용자가 말 안 한 **구체적 사실을 채웠으면 영상 전달할 때 꼭 밝힌다** ("썸녀한테 '괜찮아~' 답장한 건 제가 지어낸 거예요").

## 구조 (60초 안팎 목표, 75초 넘으면 압축)

1. **훅 (0~5초)**: 결말/클라이맥스부터. "썸녀 만나기 1분 전, 여자화장실에서 보스를 만났어요." + "근데 진짜 문제는요?" 식 떡밥
2. **⏪ 10분 전**: 되감기 장면 (`rewind=True`, `sfx="rewind"`, "어쩌다 이렇게 됐냐면요.")
3. **빌드업**: 상황 → 사건 원인. 장면당 대사 2~4개, 빠르게
4. **클라이맥스**: 깨달음은 `deadpan` + `boom` + `flash` + `shake`, 앞에 `gap` 0.3~0.5로 정적
5. **수습/결말**: 자기 디스, 연기, 탈출
6. **반전/여운**: "1분만 빨랐으면..."
7. **팔로우 유도 엔딩**: 댓글 유도 말고 **팔로우 유도**. 다음 썰 예고 카드(`teaser_card`) + "궁금하면 팔로우!" + `follow_btn()`. 다음 썰 주제를 모르면 사용자에게 묻고, 끝내 없으면 내용 가린 `"[y:???]"`로

## 말투: 오버 더빙

- **해요체로 시청자한테 말 걸기**: "여러분, 저 ~했어요."
- 속마음을 **크게**: "아니 쌰갈!!! 이거 뭐에요!!" → `scream`, 자막도 그대로 크게 (`size` 150, 빨강, `!!!!!!`). **삐- 처리 안 함** (사용자 선호)
- 완급: 흥분은 `yell`/`rap`으로 쏟아내고, 현타는 `deadpan`/`whisper`로 뚝
- 등장인물은 다른 목소리로 짧게 ("흐음...?" `ajumma`, "나 도착했어~!" `she`)

## 개그 도구함

| 장치 | 예 |
|---|---|
| 게임 프레이밍 | 상대 = **BOSS Lv.99** 체력바, 위기 = **⚠️ 긴급 퀘스트**, 판단 = **🎮 선택지** (1·2번 줄 긋고 3번 정답) |
| 겉 vs 속 | 겉: "괜찮아~ 😊" / 속: "1시간??!! 🤯" |
| 엉뚱한 비유 | "이건 표시가 아니라 **테트리스**잖아요!" |
| 수치화 | "🧠 IQ -50 📉", "50% 확률에 인생 걸기 🎲" |
| 자기 디스 괄호 | "✅ 손 한 번 더 씻기 [g:(이미 깨끗함)]" |
| 과대 포장 | "🏆 연기대상 수상 각" |
| 판정 | "결과: [r:수상함] 그러나 [c:통과] ✅" |
| 책임자 소환 | "디자이너님 한글로 써주세요 🙏" |
| 3단 몰락 | "썸 끝. 인생 끝." |

한 영상에 5~8개. 장면마다 하나씩은 웃음 포인트가 있게.

## 연출 규칙

- 자막은 짧은 펀치라인, 대사는 자연스러운 말. 자막 = 대사 받아쓰기 금지
- 장면마다 그림 하나 이상 (이모지, 소품). 글자만 있는 장면은 2개 연속 금지
- 빨강(`RED`)은 훅과 클라이맥스에만. 남발하면 효과 없음
- 큰 사건 = `boom` + `shake` 20~34 + `flash`. 작은 강조 = `shake` 10~16

## 업로드 캡션

```
{한 줄 훅} {이모지}
{공감/드립 한 줄}

다음 썰 👉 {다음 썰 제목} {이모지}
궁금하면 팔로우하고 기다려 🔔

#썰 #썰스타그램 #일상썰 #실화썰 #{주제 태그 3~5개} #공감 #릴스
```
해시태그는 10개 안팎.
