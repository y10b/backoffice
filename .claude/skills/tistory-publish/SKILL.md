# tistory-publish — 티스토리 하루 두 편

`daily-post.yml` 이 매일 초안을 만든다(06:30 KST). 이 스킬은 그중 **두 편**을 골라 검토하고 바로 공개로 올린다.
초안이 85편 쌓였는데 발행이 0편이라 유입이 0이었다 — 문제는 주제보다 발행이었다.

## 방향 (주제)

애드센스가 유일한 수익원이고(쿠팡·세시간전은 티스토리 승인 불가), 생활 주제 RPM 은 금융·세금의
1/10 수준이다. **세금·신고·4대보험·계산기** 주제만 올린다. 블로그 이름이 "N잡러 프리랜서"이니
프리랜서·N잡러가 실제로 검색하는 것(3.3% 환급, 종합소득세, 지역가입자 건보료)이 1순위다.

## 준비

```bash
test -n "$SUPABASE_URL" && test -n "$SUPABASE_SERVICE_ROLE_KEY" || echo "Supabase 키 없음 — 중단"
test -n "$TISTORY_SESSION" || echo "TISTORY_SESSION 없음 — 설정 표 tistory_session 을 쓰거나 중단"
npm ci --omit=dev
R="node --import ./scripts/ts-register.mjs"
```

## 1. 고르기

```bash
$R scripts/tistory-publish.mjs list
```

우선순위: ① 세금·신고·보험·계산기 키워드 ② 최근 초안(세율·기준이 최신) ③ 이미 올린 글과 키워드가
겹치지 않는 것. 해당이 하나도 없으면 오늘은 올리지 않는다 — 주제 밖 글을 채우려고 올리지 않는다.

## 2. 검토 — 세금 글은 틀리면 독자가 돈을 잃는다

```bash
$R scripts/tistory-publish.mjs show <id>
```

- **숫자 확인:** 세율·공제액·기준금액·신고 기한은 국세청·건강보험공단 등 공식 출처를 웹 검색으로
  대조한다. 연도가 지난 기준이면 올리지 않는다. 확인 못 한 숫자가 핵심이면 올리지 않는다
- **고지:** 계산 결과가 추정치라는 문장이나 `## 마치며` 의 면책 문장(개인 상황에 따라 다름·전문가 상담)이 있어야 한다
- **캡처 자리:** `[이미지: …]` 는 발행할 때 스크립트가 "한눈에 보는 진행 순서" HTML 카드로 바꾼다(같은 섹션에 시각 자료가 있으면 지우기만). 탈락 사유가 아니다
- **품질:** AI 상투어, 같은 문장 반복, 빈 섹션, TODO 가 있으면 올리지 않는다
- **틀린 곳이 몇 군데뿐이면 고쳐서 올린다.** 공식 출처로 확인한 바른 문장으로 바꿀 목록을 JSON 으로 만들고
  `fix` 로 저장한다. 마크다운만 바꾸고 HTML 은 /write 화면과 같은 경로로 다시 만들어 두 벌이 어긋나지 않는다
  ```bash
  echo '[["틀린 문장 그대로", "고친 문장"]]' > /tmp/fix.json
  $R scripts/tistory-publish.mjs fix <id> /tmp/fix.json
  ```
  - 문장은 본문에서 정확히 한 번 나와야 한다(아니면 실패). 확인 못 한 사실은 지우거나 "확인 필요" 로 낮춘다
  - FAQ·구조화 데이터에도 같은 오류가 있으면(스크립트가 경고한다) 고치지 말고 건너뛴다 — 화면과 스키마가 어긋난다
  - 오류가 본문 곳곳에 퍼져 있거나 핵심 계산이 틀렸으면 고치지 말고 건너뛴다(/write 에서 다시 쓰도록 보고)

## 3. 발행

```bash
$R scripts/tistory-publish.mjs publish <id>            # 공개
$R scripts/tistory-publish.mjs publish <id> --private  # 시험: 비공개, '올림' 표시 안 함
```

- 하루 **두 편**까지. 통과한 글이 한 편뿐이면 한 편만 올린다. 키워드가 겹치는 두 편을 같은 날 올리지 않는다
- 실패하면 `tistory-fail.png` 를 열어 본다
  - 로그인 화면 → 쿠키 만료. 다시 시도하지 말고 새 TSSESSION 이 필요하다고 보고
  - 셀렉터 단계 실패 → 에디터가 바뀐 것. 스크린샷으로 새 셀렉터를 찾아 스크립트를 고치는 건
    대화형 세션에서만 하고, 루틴에서는 보고만 한다
- 스크린샷은 커밋·공유하지 않는다

## 4. 보고

올린 글 제목과 키워드, 고르지 않은 이유(있다면), 확인한 공식 출처 한두 개.

## 하지 않는 것

- 하루 세 편 이상, 주제 밖 글, 확인 안 된 세율
- 카카오 아이디·비밀번호 로그인 (쿠키만 쓴다)
- 이미 `posted_tistory` 인 글 다시 올리기
