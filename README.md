# 블로그 백오피스

네이버 **공식 API**로 키워드를 고르고, AI로 초안을 만들어 네이버 블로그·티스토리에 붙여넣고,
발행 뒤 성과를 다시 회수하는 로컬 백오피스입니다. 같은 트렌드를 영상으로 푸는 갈래
(게임 쇼츠 · 유아 채널)도 함께 들어 있습니다.

세 갈래가 한 저장소에 있지만 서로 독립적입니다. **블로그만 쓸 거면 자격증명 두 개로 충분합니다.**

| 갈래 | 하는 일 | 필요한 것 |
|---|---|---|
| **블로그** | 키워드 탐색 → 초안 생성 → 네이버·티스토리 복사 | 검색광고 + Gemini |
| **게임 쇼츠** | 영상 검색 → 댓글 하이라이트 → 내 녹화로 렌더 | + YouTube, ffmpeg |
| **유아 채널** | 인기 영상 분석 → 기획 → Flow 클립 조립 | + Claude, Fish Audio, ffmpeg |

각 화면의 컨트롤 옆 **?** 에 마우스를 올리면 사용법이 나옵니다.

## 실행

```bash
npm install
npm run dev       # http://localhost:3939
npm run worker    # 영상 렌더가 필요할 때만 (별 터미널)
```

`.env.local` 에 **저장소 자격증명이 먼저 필요합니다.** 없으면 모든 조회가 안내 문구를
돌려줍니다.

```bash
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
```

[Supabase](https://supabase.com) 프로젝트를 만들고 `supabase/migrations/` 의 SQL 두 개를
실행하세요. 나머지 API 키는 `.env.local` 이 아니라 **설정 화면**에 넣는 편이 낫습니다 —
DB 에 저장돼 재시작 없이 바꿀 수 있고, 항목마다 `연결 테스트` 버튼이 있습니다.

> 왜 SQLite 가 아닌가: 배포(Vercel)는 파일시스템이 읽기 전용이고 인스턴스마다 초기화됩니다.
> 로컬 파일 DB 에는 쓸 수 없고, 써지더라도 다음 요청은 다른 인스턴스로 갑니다.

## 자격증명

설정 화면 맨 위의 **처음이신가요?** 를 펼치면 같은 표가 나옵니다.

### 필수 — 블로그

**1. 네이버 검색광고 API** · 연관 키워드와 월간 검색수를 가져오는 핵심 소스입니다.
광고를 집행하지 않아도 발급되고 무료입니다.

[searchad.naver.com](https://searchad.naver.com) 로그인 → 우측 상단 **도구 → API 사용 관리**
→ 액세스라이선스와 비밀키 발급. CUSTOMER_ID(숫자)는 같은 화면에 있습니다.

**2. Gemini API** · 블로그 본문·제목·태그를 생성합니다.
[aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 발급하세요.

무료 티어는 프로젝트당 요청 수가 정해져 있어 글 몇 개만 써도 429 가 납니다. **키를 여러 개
넣으면 쿼터에 걸린 키를 건너뜁니다** — 설정 화면에 한 줄에 하나씩 넣으세요.

### 선택 — 영상

| | 무엇에 | 비고 |
|---|---|---|
| **YouTube Data API** | 쇼츠·유아 채널의 영상 조회, 댓글 수집 | GCP 에서 v3 사용 설정. 일 10,000 단위이고 검색은 1회당 100 |
| **Claude API** | 유아 채널 기획(캐릭터·대본·장면 프롬프트) | 블로그 본문은 계속 Gemini |
| **Fish Audio** | 내레이션 음성 | `s2.1-pro-free` 는 유료와 같은 모델. 아래 주의 참고 |
| **Veo** | 영상 생성 (유료) | 별도 키 없음 — Gemini 키를 씀. 아래 주의 참고 |

### 선택 — 성과 회수

발행한 글이 실제로 읽히고 돈이 됐는지 가져옵니다. 네이버 블로그는 외부 스크립트를 막아서
**티스토리에서만 동작합니다.**

인증 방식이 서로 다릅니다.

| | GA4 | 애드센스 |
|---|---|---|
| 방식 | 서비스 계정 JSON | OAuth2 사용자 동의 |
| 이유 | Data API 가 서비스 계정을 지원 | 구글이 애드센스에는 서비스 계정을 **불허** |

**GA4** — GCP 에서 Analytics Data API 를 켜고 서비스 계정 JSON 키를 발급받아 설정 화면에
붙여넣습니다. 그 다음 **GA4 → 관리 → 속성 액세스 관리**(계정 액세스가 아님)에서 키의
`client_email` 을 **뷰어**로 추가하세요. 여기를 빠뜨리면 403 이 납니다. 속성 ID 는 측정
ID(`G-XXXXXXX`)가 아니라 **관리 → 속성 설정의 숫자**입니다.

티스토리는 **관리 → 플러그인 → 구글 애널리틱스**에 측정 ID 를 넣으면 끝입니다. 데이터는
소급되지 않으니 빨리 달수록 이득입니다.

**애드센스** — GCP → 사용자 인증 정보 → **OAuth 클라이언트 ID(웹 애플리케이션)** 를 만들고
승인된 리디렉션 URI 에 아래를 **정확히 그대로** 등록하세요.

```text
http://localhost:3939/api/oauth/callback
```

설정 화면에 클라이언트 ID/시크릿을 저장한 뒤 `애드센스 연결` 을 누르면 동의 후 연결됩니다.
OAuth 동의 화면이 **"테스트" 상태면 refresh token 이 7일마다 만료**되니 프로덕션으로
게시하세요(내부 도구라 심사 없이 전환됩니다).

### 현재 발급이 막힌 것

**네이버 개발자센터의 `검색` 과 `데이터랩`** 은 신규 발급이 안 됩니다. 앱을 등록해도 사용
API 목록에 없고, 호출하면 `401 Scope Status Invalid` 가 옵니다 — 키는 유효한데 앱에 권한이
없다는 뜻입니다.

이 둘은 블로그 문서수와 검색어 트렌드에 쓰려던 것입니다. 코드 경로와 UI 열은 그대로 두어,
승인된 키가 생기면 설정 화면에 넣는 것만으로 채워집니다. 없으면 비워두세요 — **광고 흡수율**과
**모바일 비중**이 그 자리를 대신합니다.

## 블로그

1. **키워드 탐색** — 시드 키워드(최대 5개)를 넣고 조회 → 연관 키워드 표
2. 후보를 체크하고 **경쟁 분석** → 상위권을 누가 잡고 있는지 확인
3. 마음에 드는 키워드의 **작성** → 메인 키워드로 넘어감
4. **글 작성** — `서브 키워드 제안` 으로 조합 후보 5개를 받고 하나 선택
5. **초안 생성** — 제목(메인+서브 포함), 본문, 태그, 메타 설명, FAQ 생성 + 자동 저장
6. **복사** — 네이버는 서식 유지 복사, 티스토리는 HTML 복사
7. **글 목록** — 발행 여부를 수동 체크로 관리

### 키워드 표 읽는 법

| 열 | 출처 | 의미 |
|---|---|---|
| 월간 검색 | 검색광고 키워드도구 | 최근 한 달 검색수(PC+모바일). `9`는 네이버가 `< 10`으로 가린 값 |
| 광고 단가 | 검색광고 입찰가 추정 | 1위 노출 예상 입찰가(모바일). **애드센스 단가의 대리 지표** |
| 수익 잠재력 | 계산값 | 검색수 × 단가 ÷ 1000. 트래픽과 단가를 묶은 비교 지수(금액 아님) |
| 모바일 | 계산값 | 모바일 검색 비중. **높을수록 블로그 유입에 유리** |
| 광고 흡수 | 계산값 | 월평균 광고 클릭수 ÷ 월간 검색수. **낮을수록 자연 결과로 갈 여지가 크다** |
| 광고 | 검색광고 키워드도구 | 경쟁정도(높음/중간/낮음)와 월평균 노출 광고수(0~15) |
| 최신글 | 검색결과 분석 | 상위 노출 글 중 최근 30일 내 비율. **높으면 계속 갈아치워지는 레드오션** |
| 인플루언서 | 검색결과 분석 | 상위 노출 블로그 중 인플루언서 비율. 높으면 일반 블로그가 밀림 |
| 진입 난이도 | 계산값 | 위 둘을 절반씩 섞은 0~100 |
| 문서수 · 경쟁률 · 추세 | 검색 API · 데이터랩 | *현재 발급 불가라 비어 있음* |

전부 공식 지표가 아니라 경험칙입니다. 절대값보다 같은 표 안에서의 상대 비교로 쓰세요.

### 뭘 보고 고르나

문서수를 못 쓰는 지금은 **광고 흡수율**이 가장 쓸모 있습니다. 광고주가 돈을 안 쓰는 키워드는
상업적 의도가 낮은 정보성 검색이라는 뜻이고, 그런 검색일수록 사용자가 블로그 글을 끝까지
읽습니다. 여기에 **모바일 비중**이 높으면 더 좋습니다.

```
7월제주도날씨    31,960   모바일 94.5%   광고 흡수 0%    ← 정보성, 블로그에 적합
부산숙소        108,300   모바일 80.1%   광고 흡수 2.4%   ← 예약 의도, 광고가 가져감
```

검색량만 보면 부산숙소가 3배지만, 블로그로 실제 유입될 여지는 앞쪽이 큽니다.

**애드센스를 달았다면 해석이 뒤집힙니다.** 광고가 아예 안 붙는 키워드는 트래픽이 와도 수익이
거의 없습니다. 그때는 기본값인 `수익 잠재력 높은 순` 으로 두세요.

정렬은 **잘라내기 전 전체 후보**에 적용되므로 검색량 상위에 없는 키워드도 발굴됩니다.
(단 **경쟁률·문서수 정렬**은 문서수를 조회한 뒤에야 알 수 있어 상위 N개 안에서만 정렬됩니다.)

### 경쟁 분석

광고 흡수율로 후보를 좁혔으면 최대 20개를 체크하고 **경쟁 분석**을 누르세요. 두 지표는 서로
다른 것을 봅니다 — **광고 흡수율은 수요의 성격**(정보성이냐 구매성이냐), **진입 난이도는 지금
공급 상태**(누가 상위를 잡고 있나)입니다.

```
8월제주날씨    광고 흡수 0%   진입 난이도 57   최신글 90%, 중앙연령 14일
제주도박물관   광고 흡수 0.1%  진입 난이도 17   최신글 20%, 중앙연령 48일
```

둘 다 정보성이지만, 앞쪽은 8월이라 새 글이 쏟아지는 중이고 뒤쪽은 오래된 글이 상위에 남아
비집고 들어갈 자리가 있습니다.

이 기능은 공식 API 가 아니라 **공개 검색 페이지를 읽습니다.** 버튼을 눌렀을 때만, 동시 2개 ·
요청 간 0.4초로 돕니다(20개에 약 25초). 네이버가 마크업을 바꾸면 깨지고, 그때는 그렇게
알려줍니다. 상시 크롤러가 아니므로 이 정도 빈도를 유지하세요.

### 붙여넣기 요령

| 대상 | 버튼 | 방법 |
|---|---|---|
| 네이버 블로그 | `네이버 본문 (서식 유지)` | 스마트에디터 ONE 본문에 그대로 ⌘V. 소제목·굵게·목록이 살아납니다 |
| 티스토리 | `티스토리 본문 (HTML)` | 에디터를 **HTML 모드**로 전환한 뒤 ⌘V |

제목·태그·JSON-LD 는 별도 버튼으로 복사합니다.

## 게임 쇼츠

**검색 → 행 클릭 → 하이라이트 → 내 녹화로 렌더** 흐름입니다.

댓글에 `3:24 여기서 소름` 같은 타임스탬프가 몰리는 지점이 실제 하이라이트입니다. 유튜브
내부 API 에는 재생 그래프(`mostReplayed`)가 있지만 공개 Data API 에는 없어서, 사람들이 직접
찍어둔 타임스탬프를 집계해 대체합니다. **게임·음악·스포츠에서 가장 잘 맞습니다.**

- 좋아요는 로그 가중 — 선형으로 더하면 좋아요 3천짜리 하나가 나머지를 덮습니다
- 이웃 구간을 합쳐 피크를 고릅니다 — 사람마다 초를 다르게 적어 같은 장면이 쪼개집니다
- **리드인** — 사람은 좋은 장면이 시작될 때가 아니라 **반응한 뒤에** 댓글을 씁니다.
  타임스탬프를 그대로 시작점으로 쓰면 클라이맥스가 지나간 자리에서 시작합니다(기본 4초 앞)
- 장면 전환에 스냅 — 대사 중간에서 시작하지 않게 경계로 당깁니다

**분석은 어느 영상에든 돌립니다.** 나오는 건 "몇 초 지점이 먹혔나"라는 정보이지 그 영상을 쓸
권리가 아닙니다. 렌더 입력은 **내가 직접 플레이해 녹화한 파일**입니다 — 게임은 그렇게 하면
온전히 내 소재가 됩니다.

## 유아 채널

**인기 영상 클릭 → 구성 분석 → 기획 → Flow 에서 클립 생성 → 조립** 흐름입니다.

행을 누르면 그 영상의 제목·설명란·길이를 Claude 에 넘겨 **왜 그 영상이 먹혔는지 구성을 먼저
분석**하고(몇 개 항목을 어떤 순서로, 후렴을 어디서 반복하는지), 그 구조로 **완전히 새로운
캐릭터와 소재**의 기획을 만듭니다. 주제도 모델이 정하니 입력은 선택입니다.

전적으로 AI 로 생성하면 **장면마다 캐릭터가 달라지는 게 최대 문제**입니다. 기획안의
`캐릭터 고정 묘사`(영문)를 모든 장면 프롬프트 앞에 똑같이 붙여 외형을 고정합니다 — 복사
버튼이 이미 붙여줍니다.

```
3단계  장면 행마다 [복사] → Flow 에 붙여넣어 클립 하나 생성 → 다운로드
4단계  받은 클립 전부 한 번에 드롭 → 자막·내레이션 얹어 한 편으로 조립
```

Flow 는 한 번에 한 클립씩 만들므로 장면 단위 복사가 실제 작업 순서와 맞습니다. 업로드는
파일명 속 숫자 순으로 정렬하니 `scene-1 … scene-10` 처럼 번호를 넣으면 순서가 맞습니다.

**유아 채널에서 먼저 알아야 할 것**

- 업로드 시 **아동용(Made for Kids)** 지정이 필요하고, 그러면 유튜브가 **댓글을 끄고
  개인맞춤 광고를 막아** RPM 이 크게 떨어집니다. 게임 채널의 댓글 하이라이트도 그래서
  유아 채널에는 적용되지 않습니다.
- **기존 캐릭터를 닮게 만들면 침해입니다.** 포맷과 구성(반복 후렴, 색깔 소개 순서)은
  저작권 대상이 아니지만 캐릭터 디자인은 다릅니다. 프롬프트에 제약을 걸어두었고, 기획안에
  `사람이 확인할 항목` 이 함께 나옵니다.
- AI 대량생산 아동 콘텐츠는 유튜브가 특히 강하게 단속합니다. 편수보다 편당 완성도로 가세요.

### 영상 생성 — 무료 경로와 유료 경로

**구글 플로우(flow.google)는 API 가 없습니다.** 웹 UI 제품이라 코드에서 부를 수 없습니다.
그래서 두 갈래입니다.

| | 방식 | 비용 |
|---|---|---|
| **무료** | Flow 웹에서 프롬프트를 붙여넣어 만들고 내려받아 4단계에 올림 | 플랜 크레딧 |
| **유료** | `렌더` 버튼으로 Veo API 직접 호출 | 8초 클립 $1.2~3.2 |

Veo 는 별도 키가 없습니다 — **Gemini 키를 그대로 씁니다**(다중 키 로테이션도 재활용).
단 Veo 는 무료 티어에 없어서 **결제가 설정된 프로젝트의 키**여야 합니다.

Flow 웹 자동화는 하지 않습니다. 구글이 자동화 브라우저를 탐지해 막고, 무엇보다 그 계정이
Gemini 키·GA4·애드센스를 쓰는 계정이라 정지되면 백오피스 전체가 같이 죽습니다.

**Fish Audio 무료 등급 주의** — `s2.1-pro-free` 는 유료와 같은 모델이지만 *"일부 상용
시나리오에 제약이 있을 수 있다"* 고 공지돼 있습니다. 수익화 채널에 쓸 거면 설정에서
`s2.1-pro` 로 올리세요.

## 성과 회수

`성과` 화면에서 GA4 조회수와 애드센스 수익을 글 단위로 붙여 봅니다. 조회수만 오르고 수익이
안 따라오면 광고가 안 붙는 주제라는 뜻이니, 키워드 탐색의 정렬을 `수익 잠재력` 으로 바꾸는
식으로 되돌아갑니다.

체류시간이 30초 미만이면 제목과 본문이 안 맞아 바로 나간 것입니다 — 검색 의도를 다시 보세요.

## 자동 작성

`/api/cron/daily-post` 가 하루 한 편을 자동 생성합니다. GitHub Actions 가 `CRON_SECRET`
으로 호출합니다. 판단 로직을 전부 서버에 둬서 워크플로는 curl 한 줄입니다.

SERP 경쟁 분석은 하지 않습니다 — 네이버 검색 페이지를 읽는 것이라 실패해도 글은 나와야 하고,
자동 실행에서는 사람이 결과를 보고 판단할 수도 없습니다. 검색광고 데이터만으로 고릅니다.

## 배포

Vercel 에 올릴 수 있지만 **영상 렌더는 로컬에서만 됩니다.** ffmpeg 바이너리 크기와 실행 시간
제한 때문입니다. 그래서 조립·렌더는 큐(`render_jobs`)에 담고, 로컬 워커가 가져가 처리합니다.

```bash
npm run worker    # 배포본이 담은 작업을 로컬이 폴링해 처리
```

배포 시 `BACKOFFICE_PASSWORD` 를 **반드시** 넣으세요. 비우면 인증이 꺼지고, URL 을 아는
누구나 API 키와 수익 데이터를 봅니다. `SESSION_SECRET` 과 `APP_ORIGIN` 도 함께 설정하세요.

## 알아둘 점

- **자동 발행은 없습니다.** 네이버 글쓰기 API 는 폐지됐고 티스토리 Open API 도 사실상
  종료돼서, 자동 발행은 브라우저 자동화 외에 방법이 없습니다. 복사용 결과물까지만 만듭니다.
- **남의 영상 파일은 쓰지 않습니다.** 댓글·제목·설명란 분석은 어느 영상에든 하지만, 그 결과는
  "무엇이 먹혔나"라는 정보이지 그 영상을 쓸 권리가 아닙니다. 렌더 소재는 내가 녹화한 것,
  CC 라이선스, 공개 도메인, AI 로 생성한 것뿐입니다.
- **생성된 본문의 수치·날짜·가격은 검증하세요.** 검색 그라운딩으로 억제하고는 있지만
  완전하지 않습니다.
- 크리에이터 어드바이저는 연동하지 않습니다. 내부 API 가 HMAC 서명으로 막혀 있고 우회하지
  않기로 했습니다. 경위는 [DEVLOG.md](DEVLOG.md) 5장에 있습니다.

## 호출 한도

| API | 한도 | 이 앱에서의 소비 |
|---|---|---|
| 검색광고 키워드도구 | 계정별 | 조회 1회당 1호출 |
| YouTube Data API | 일 10,000 단위 | **검색 100** · 영상 조회 1 · 댓글 1 |
| Gemini | 티어별 | 글 1편당 1~2회(그라운딩 켜면 2패스) |
| 검색 API · 데이터랩 | 일 25,000 / 1,000 | *발급 불가라 해당 없음* |

YouTube 검색이 가장 비쌉니다. 하루 100회 검색하면 할당량의 대부분이 사라지니, 검색은 아껴
쓰고 하이라이트 조회(1단위)를 많이 쓰세요.

설계 결정과 도중에 막힌 것들의 기록은 [DEVLOG.md](DEVLOG.md) 에 있습니다.
