# 블로그 백오피스

네이버 크리에이터 어드바이저에서 주제별 인기 키워드를 가져와, **메인 키워드 + 서브 키워드**로
제목을 잡고 Gemini로 본문 초안을 만든 뒤, 네이버 블로그와 티스토리에 각각 맞는 형식으로 복사하는
로컬 백오피스입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3939
```

첫 실행 후 **설정** 화면에서 두 가지를 등록하세요.

### 1. 네이버 쿠키

크리에이터 어드바이저는 공개 API가 없어 로그인 쿠키로 내부 엔드포인트를 호출합니다.

1. 크롬에서 `creator-advisor.naver.com` 로그인
2. 개발자도구(⌥⌘I) → Network 탭 → 통계 요청 아무거나 클릭
3. Headers → Request Headers → `cookie` 값 **전체** 복사
4. 설정 화면에 붙여넣고 저장

쿠키는 며칠~몇 주 뒤 만료됩니다. 조회 시 `HTTP 401`이 뜨면 같은 방법으로 다시 붙여넣으면 됩니다.

### 2. Gemini API 키

[aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 발급받아 설정 화면에 등록합니다.
`.env.local`의 `GEMINI_API_KEY`로도 되지만, 설정 화면에 넣으면 재시작 없이 바꿀 수 있습니다.

## 사용 흐름

1. **키워드 탐색** — 주제·기준일을 골라 조회 → 인기 키워드 표
2. 마음에 드는 키워드의 **작성** 버튼 → 메인 키워드로 넘어감
3. **글 작성** — `서브 키워드 제안`으로 조합 후보 5개를 받고 하나 선택
4. **초안 생성** — 제목(메인+서브 포함), 본문, 태그 10개, 메타 설명 생성 + 자동 저장
5. **복사** — 네이버는 서식 유지 복사, 티스토리는 HTML 복사
6. **글 목록** — 발행 여부를 수동 체크로 관리

## 붙여넣기 요령

| 대상 | 버튼 | 방법 |
|---|---|---|
| 네이버 블로그 | `네이버 본문 (서식 유지)` | 스마트에디터 ONE 본문에 그대로 ⌘V. 소제목·굵게·목록이 살아납니다. |
| 티스토리 | `티스토리 본문 (HTML)` | 에디터를 **HTML 모드**로 전환한 뒤 ⌘V |

제목·태그는 별도 버튼으로 복사합니다.

## 엔드포인트가 안 맞을 때

크리에이터 어드바이저 내부 API는 비공개라 경로·파라미터가 예고 없이 바뀝니다. 그래서 엔드포인트를
코드에 고정하지 않았습니다.

- `HTTP 404`가 뜨면 → **설정 → 엔드포인트 프리셋** JSON을 DevTools에서 본 실제 URL에 맞게 수정
- 더 빠른 방법: **키워드 탐색** 화면의 `DevTools cURL 붙여넣기`에 요청을 Copy as cURL로 복사해 넣으면
  그 URL로 바로 조회합니다 (인증은 저장된 쿠키 사용)

응답 스키마도 고정하지 않았습니다. 파서가 JSON을 훑어 "키워드처럼 생긴 필드를 가진 객체 배열" 중
가장 큰 것을 자동으로 찾습니다. 그래도 못 찾으면 결과 카드 하단의 **원본 응답** 패널에서 실제
구조를 확인할 수 있습니다.

프리셋 JSON에서 치환되는 변수: `{{date}}` `{{dateStart}}` `{{dateEnd}}` `{{categoryId}}` `{{limit}}`

## 구조

```
src/
  lib/
    naver.ts       크리에이터 어드바이저 클라이언트 + 스키마 유연 파서
    curl.ts        DevTools cURL 파서 (셸 인용 규칙 처리)
    gemini.ts      초안 생성 / 서브 키워드 제안 (responseSchema로 구조화 출력)
    markdown.ts    마크다운 → HTML (에디터 붙여넣기용 단순 태그, XSS 이스케이프)
    db.ts          node:sqlite (네이티브 의존성 없음)
    categories.ts  네이버 블로그 주제 분류 ID
  app/
    page.tsx       키워드 탐색
    write/         글 작성 · 미리보기 · 복사
    posts/         글 목록 · 발행 체크
    settings/      쿠키 · API 키 · 엔드포인트 프리셋
    api/           keywords · suggest · generate · posts · settings
```

데이터는 `data/backoffice.db` (SQLite)에만 저장됩니다. 쿠키와 API 키도 여기 들어가니
이 파일은 공유하지 마세요. `.gitignore`에 이미 제외돼 있습니다.

## 알아둘 점

- **자동 발행은 없습니다.** 네이버 블로그 글쓰기 API는 폐지됐고 티스토리 Open API도 사실상 종료돼서,
  자동 발행은 브라우저 자동화 외에 방법이 없습니다. 지금은 복사용 결과물까지만 만듭니다.
- 생성된 본문의 **수치·날짜·가격은 검증하세요.** 프롬프트로 억제하고는 있지만 완전하지 않습니다.
- 제목 옆 `메인 포함` / `서브 포함` 배지와 본문의 키워드 등장 횟수 배지로 키워드가 제대로 들어갔는지
  확인할 수 있습니다.
