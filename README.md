# 블로그 백오피스

네이버 **공식 API**로 키워드 검색량·경쟁률·추세를 뽑아 **메인 키워드 + 서브 키워드**로
제목을 잡고 Gemini로 본문 초안을 만든 뒤, 네이버 블로그와 티스토리에 각각 맞는 형식으로
복사하는 로컬 백오피스입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3939
```

첫 실행 후 **설정** 화면에서 자격증명을 등록하세요. 모두 공식 발급 키라 쿠키처럼 만료되지
않습니다. 각 항목마다 **연결 테스트** 버튼이 있어 바로 확인할 수 있습니다.

### 1. 네이버 검색광고 API (필수)

연관 키워드와 월간 검색수를 가져오는 핵심 소스입니다. 광고를 집행하지 않아도 발급됩니다.

1. [searchad.naver.com](https://searchad.naver.com) 로그인
2. 우측 상단 **도구 → API 사용 관리**
3. **액세스라이선스**와 **비밀키** 발급, 같은 화면의 **CUSTOMER_ID**(숫자) 확인
4. 설정 화면에 세 값을 넣고 저장

### 2. 네이버 개발자센터 — 현재 신규 발급 불가

블로그 문서수와 검색어 트렌드에 쓰려던 소스입니다. **지금은 새로 발급받을 수 없습니다.**
앱을 등록해도 사용 API 목록에 `검색`과 `데이터랩`이 없고, 호출하면 이렇게 돌아옵니다.

```
401 Scope Status Invalid
```

키 자체는 유효하고 앱에 그 API 권한이 없다는 뜻입니다. 기존에 승인된 키가 있다면 설정
화면에 넣으면 문서수·경쟁률·추세 열이 바로 채워집니다. 없으면 비워두세요 — 아래 **광고
흡수율**과 **모바일 비중**이 그 자리를 대신합니다.

### 3. Gemini API 키

[aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 발급받아 설정 화면에
등록합니다. `.env.local`로도 되지만, 설정 화면에 넣으면 재시작 없이 바꿀 수 있습니다.

### 4. GA4 · 애드센스 (성과 회수)

발행한 글이 실제로 읽히고 돈이 됐는지를 백오피스로 가져옵니다. 네이버 블로그는 외부
스크립트를 막아서 **티스토리에서만 동작합니다.**

인증 방식이 서로 다릅니다.

| | GA4 | 애드센스 |
|---|---|---|
| 방식 | 서비스 계정 JSON | OAuth2 사용자 동의 |
| 이유 | Data API 가 서비스 계정을 지원 | 구글이 애드센스에는 서비스 계정을 **불허** |

**GA4** — GCP 에서 Analytics Data API 를 켜고 서비스 계정 JSON 키를 발급받아 설정 화면에
붙여넣습니다. 그 다음 **GA4 → 관리 → 속성 액세스 관리**(계정 액세스가 아님)에서 키의
`client_email` 을 **뷰어**로 추가하세요. 여기를 빠뜨리면 403 이 납니다. 속성 ID 는 측정
ID(`G-XXXXXXX`)가 아니라 **관리 → 속성 설정의 숫자**입니다.

마지막으로 블로그에 태그를 답니다. 티스토리는 **관리 → 플러그인 → 구글 애널리틱스**에
측정 ID 를 넣으면 끝입니다. 데이터는 소급되지 않으니 빨리 달수록 이득입니다.

**애드센스** — GCP → 사용자 인증 정보 → **OAuth 클라이언트 ID(웹 애플리케이션)** 를 만들고
승인된 리디렉션 URI 에 아래를 **정확히 그대로** 등록하세요.

```text
http://localhost:3939/api/oauth/callback
```

클라이언트 ID/시크릿을 설정 화면에 저장한 뒤 `애드센스 연결` 을 누르면 동의 후 연결됩니다.
OAuth 동의 화면이 **"테스트" 상태면 refresh token 이 7일마다 만료**되니 프로덕션으로
게시하세요(내부 도구라 심사 없이 전환됩니다).

## 사용 흐름

1. **키워드 탐색** — 시드 키워드(최대 5개)를 넣고 조회 → 연관 키워드 표
2. 후보를 체크하고 **경쟁 분석** → 상위권을 누가 잡고 있는지 확인
3. 마음에 드는 키워드의 **작성** 버튼 → 메인 키워드로 넘어감
4. **글 작성** — `서브 키워드 제안`으로 조합 후보 5개를 받고 하나 선택
5. **초안 생성** — 제목(메인+서브 포함), 본문, 태그 10개, 메타 설명 생성 + 자동 저장
6. **복사** — 네이버는 서식 유지 복사, 티스토리는 HTML 복사
7. **글 목록** — 발행 여부를 수동 체크로 관리

## 키워드 표 읽는 법

| 열 | 출처 | 의미 |
|---|---|---|
| 월간 검색 | 검색광고 키워드도구 | 최근 한 달 검색수(PC+모바일). `9`는 네이버가 `< 10`으로 가린 값 |
| 광고 단가 | 검색광고 입찰가 추정 | 1위 노출 예상 입찰가(모바일). **애드센스 단가의 대리 지표** |
| 수익 잠재력 | 계산값 | 검색수 × 단가 ÷ 1000. 트래픽과 단가를 묶은 비교 지수(금액 아님) |
| 모바일 | 계산값 | 모바일 검색 비중. **높을수록 블로그 유입에 유리** |
| 광고 흡수 | 계산값 | 월평균 광고 클릭수 ÷ 월간 검색수. **낮을수록 자연 결과로 갈 여지가 크다** |
| 광고 | 검색광고 키워드도구 | 경쟁정도(높음/중간/낮음)와 월평균 노출 광고수(0~15) |
| 최신글 | 검색결과 분석 | 상위 노출 글 중 최근 30일 내 비율. **높으면 계속 갈아치워지는 레드오션** |
| 인플루언서 | 검색결과 분석 | 상위 노출 블로그 중 인플루언서 비율. 높으면 일반 블로그가 밀림 |
| 진입 난이도 | 계산값 | 위 둘을 절반씩 섞은 0~100 |
| 문서수 | 검색 API | 그 키워드의 블로그 문서 총 개수 — *현재 발급 불가라 비어 있음* |
| 경쟁률 | 계산값 | 문서수 ÷ 월간 검색수. 낮을수록 노출이 쉽다 — *문서수가 있을 때만* |
| 추세 | 데이터랩 | 최근 26주 상대지수 — *현재 발급 불가라 비어 있음* |

전부 공식 지표가 아니라 경험칙입니다. 절대값보다 같은 표 안에서의 상대 비교로 쓰세요.

### 애드센스를 단다면

기본 정렬이 **수익 잠재력 높은 순**입니다. 검색량만 많고 단가가 바닥인 키워드를 걸러줍니다.

주의할 점은 **광고 흡수율의 해석이 뒤집힌다**는 것입니다. 순수 유입만 원하면 광고가 안
가져가는(흡수율 낮은) 키워드가 좋지만, 애드센스는 광고주가 돈을 쓰는 주제라야 단가가
붙습니다. 광고가 아예 안 붙는 키워드는 트래픽이 와도 수익이 거의 없습니다.

단가는 네이버 검색광고 입찰가라 애드센스 CPC와 같은 값이 아닙니다. 같은 시장에서 같은
광고주가 그 주제에 얼마를 쓰는지를 보여주는 **상관 지표**로만 쓰세요.

### 뭘 보고 고르나

문서수를 못 쓰는 지금은 **광고 흡수율**이 가장 쓸모 있습니다. 광고주가 돈을 안 쓰는
키워드는 상업적 의도가 낮은 정보성 검색이라는 뜻이고, 그런 검색일수록 사용자가 블로그
글을 끝까지 읽습니다. 여기에 **모바일 비중**이 높으면 더 좋습니다.

```
7월제주도날씨    31,960   모바일 94.5%   광고 흡수 0%    ← 정보성, 블로그에 적합
부산숙소        108,300   모바일 80.1%   광고 흡수 2.4%   ← 예약 의도, 광고가 가져감
```

검색량만 보면 부산숙소가 3배지만, 블로그로 실제 유입될 여지는 앞쪽이 큽니다.

정렬을 **광고 흡수율 낮은 순**으로 두면 이런 키워드가 위로 올라옵니다. 이 정렬은 잘라내기
전에 전체 연관 키워드를 대상으로 적용되므로, 검색량 상위에 없는 키워드도 발굴됩니다.
(단 **경쟁률·문서수 정렬**은 문서수를 조회한 뒤에야 알 수 있어 검색량 상위 N개 안에서만
정렬됩니다.) 시드로 직접 넣은 키워드는 비교 기준이 되도록 항상 맨 위에 붙습니다.

### 경쟁 분석 (2단계)

광고 흡수율로 후보를 좁혔으면, 체크박스로 최대 20개를 고르고 **경쟁 분석** 버튼을 누르세요.
각 키워드의 네이버 블로그 검색 결과를 읽어 상위권 상태를 봅니다.

두 지표는 서로 다른 것을 봅니다. **광고 흡수율은 수요의 성격**(정보성이냐 구매성이냐)이고,
**진입 난이도는 지금 공급 상태**(누가 상위를 잡고 있나)입니다. 그래서 엇갈릴 수 있습니다.

```
8월제주날씨    광고 흡수 0%   진입 난이도 57   최신글 90%, 중앙연령 14일
제주도박물관   광고 흡수 0.1%  진입 난이도 17   최신글 20%, 중앙연령 48일
```

둘 다 광고가 안 가져가는 정보성 키워드지만, 앞쪽은 지금이 8월이라 새 글이 쏟아지는
중이고 뒤쪽은 오래된 글이 상위에 남아 있어 비집고 들어갈 자리가 있습니다. 광고 흡수율만
봤으면 구분되지 않았을 차이입니다.

이 기능은 공식 API가 아니라 **공개 검색 페이지를 읽습니다.** 버튼을 눌렀을 때만, 동시 2개
· 요청 간 0.4초 간격으로 돕니다. 20개에 약 25초 걸립니다. 네이버가 마크업을 바꾸면 깨질 수
있고, 그때는 `결과를 하나도 읽지 못했습니다` 라고 알려줍니다. 상시로 돌리는 크롤러가
아니므로 이 정도 빈도를 유지하세요.

## 호출 한도

| API | 한도 | 이 앱에서의 소비 |
|---|---|---|
| 검색광고 키워드도구 | 계정별 제한 | 조회 1회당 1호출 |
| 검색 API | 일 25,000회 | 문서수 조회 시 **키워드 1건당 1호출** |
| 데이터랩 | 일 1,000회 | 조회 1회당 1호출 (키워드 5개까지 한 번에) |

아래 둘은 현재 발급이 막혀 해당 없습니다. 승인된 키가 생기면 문서수가 가장 많이 먹습니다 —
`개수`를 50으로 두면 조회 한 번에 50회입니다. 느리면 `블로그 문서수 · 경쟁률 함께 조회`
체크를 끄세요.

데이터랩은 API 제한상 한 번에 5개 키워드까지만 됩니다. 표에서 원하는 키워드를 체크하고
`선택 N개 추세 보기`를 누르면 그 키워드들만 따로 조회합니다.

## 붙여넣기 요령

| 대상 | 버튼 | 방법 |
|---|---|---|
| 네이버 블로그 | `네이버 본문 (서식 유지)` | 스마트에디터 ONE 본문에 그대로 ⌘V. 소제목·굵게·목록이 살아납니다. |
| 티스토리 | `티스토리 본문 (HTML)` | 에디터를 **HTML 모드**로 전환한 뒤 ⌘V |

제목·태그는 별도 버튼으로 복사합니다.

## 구조

```
src/
  lib/
    searchad.ts    검색광고 키워드도구 클라이언트 (HMAC 서명)
    openapi.ts     검색 API 문서수 + 데이터랩 검색어트렌드 (현재 발급 불가)
    serp.ts        블로그 검색 결과 파싱 → 상위권 신선도 · 인플루언서 점유율
    research.ts    소스를 합쳐 키워드 표를 만드는 오케스트레이션
    competition.ts 경쟁률 등급 (서버·클라이언트 공용 순수 함수)
    gemini.ts      초안 생성 / 서브 키워드 제안 (responseSchema로 구조화 출력)
    markdown.ts    마크다운 → HTML (에디터 붙여넣기용 단순 태그, XSS 이스케이프)
    db.ts          node:sqlite (네이티브 의존성 없음)
  app/
    page.tsx       키워드 탐색
    write/         글 작성 · 미리보기 · 복사
    posts/         글 목록 · 발행 체크
    settings/      API 자격증명
    api/           keywords · serp · trend · suggest · generate · posts · settings
```

데이터는 `data/backoffice.db` (SQLite)에만 저장됩니다. API 키도 여기 들어가니 이 파일은
공유하지 마세요. `.gitignore`에 이미 제외돼 있습니다.

## 알아둘 점

- **자동 발행은 없습니다.** 네이버 블로그 글쓰기 API는 폐지됐고 티스토리 Open API도 사실상
  종료돼서, 자동 발행은 브라우저 자동화 외에 방법이 없습니다. 지금은 복사용 결과물까지만
  만듭니다.
- 크리에이터 어드바이저(내 블로그 유입 통계)는 공개 API가 없고 내부 API는 HMAC 서명으로
  막혀 있어 연동하지 않습니다. 자세한 경위는 [DEVLOG.md](DEVLOG.md) 5장에 있습니다.
- 생성된 본문의 **수치·날짜·가격은 검증하세요.** 프롬프트로 억제하고는 있지만 완전하지
  않습니다.
- 제목 옆 `메인 포함` / `서브 포함` 배지와 본문의 키워드 등장 횟수 배지로 키워드가 제대로
  들어갔는지 확인할 수 있습니다.
